# Ruta lógica

Juego de lógica matemática de Math Hacking. Arma un algoritmo para que Lúa llegue al portal con la suma exacta.

[Abre el juego en GitHub Pages](https://barragana.github.io/math-hacking-sesion-1/ruta-logica/). También puedes abrir `index.html` directamente en tu navegador.

Los siete retos practican secuencias, saltos, bucles, paridad y el operador lógico Y. Usa **Paso a paso** para ver cómo cambia la suma después de cada instrucción. El progreso se guarda en el navegador.
